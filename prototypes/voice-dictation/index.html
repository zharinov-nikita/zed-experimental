Посмотри, как insert_text в MessageEditor работает с undo. Если вставлять по слову, каждый вызов будет отдельной транзакцией?

Да. insert_text вызывает Editor::insert, а тот открывает и закрывает транзакцию на каждый вызов. Если стримить транскрипт по слову, отмена будет откатывать по одному слову.

Есть два способа сделать один undo-шаг:

  • Обернуть серию вставок в editor.transact(window, cx, |editor, window, cx| { ... }).
  • Не писать в композер во время записи вообще, а вставить весь текст одним вызовом при Commit.

Второй вариант проще и совпадает с тем, что окно диктовки не трогает композер до Commit.

Тогда второй вариант.
