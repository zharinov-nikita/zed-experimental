# Голосовая диктовка: решение по прототипу

Дата: 2026-09-04. Прототип: `index.html` в этой папке (открывать двойным кликом).

## Что выбрано

Утверждённая конфигурация, в адресной строке прототипа:

```
index.html?variant=A&mic=right&entity=chip&open=no
```

- **Окно диктовки: вариант A, Popover у курсора.** Контейнер `Popover` / `elevation_2`, привязан к курсору
  в композере. Отвергнуты: B (на месте композера), C (Section над композером), D (Modal по центру панели).
- **Кнопка микрофона: справа, рядом с Send.** `IconButton(Mic, Small, Muted)`; во время записи
  `ButtonStyle::Tinted(Error)` с иконкой `Color::Error` и пульсацией, как у кнопки Stop генерации.
- **Dictation Block: чип.** Тот же механизм, что у @-упоминаний: crease в буфере композера, свёрнутый
  в `MentionCrease`-подобную кнопку «Диктовка · 1:03 · 46 слов». Свёрнут по умолчанию. Наведение
  показывает `Tooltip` с текстом, клик открывает окно диктовки в просмотре, Backspace удаляет целиком.
  При отправке crease разворачивается в полный текст. Отвергнуты: свободный текст, блок-Section.

## Язык интерфейса

Все надписи окна и кнопок английские, как весь UI Zed. Русский в прототипе только в содержимом
диктовки и сообщений. Строки: `Dictate`, `Stop Dictation`, `Accept`, `Review`, `Resume`, `Raw`,
`Processed`, `Cancel`, `Accept Raw`, `Retry`, `Post-processing Unavailable`,
`Dictation · 1:03 · 46 words`, `Open in Dictation Window`, `Expand` / `Collapse`.

## Каркас окна, одинаковый для всех состояний

Текст сверху, одна строка снизу: слева таймер (в записи с точкой `Indicator::dot` цвета error),
справа только `KeyBinding`-подсказки. Кнопок в окне нет, кроме «Повторить» внутри `Callout` при ошибке.

| Состояние | Текст | Подсказки |
|---|---|---|
| Запись | живой транскрипт, хвост цветом `predictive` | Accept Ctrl-Shift-Space · Review Esc |
| Просмотр | результат постобработки, редактируемый | Resume Ctrl-Shift-Space · Raw Tab · Accept Enter · Cancel Esc |
| Ошибка постобработки | сырой текст + `Callout` Warning сверху | Accept Raw Enter · Cancel Esc |
| Продолжение блока | принятый текст + новые слова в конец | как в записи |

## Поведение, проверенное на прототипе

- Длинная диктовка: окно растёт до ~9 строк, дальше показывает хвост как терминал; в просмотре скролл.
- После Enter чип встаёт у курсора в композере; композер ограничен 8 строками (настройка Zed), дальше скролл.
- После Send чип виден в сообщении в истории; правка сообщения — штатная функция Zed
  (доступна только для агентов с поддержкой отката диалога).
- Продолжение блока: только из открытого окна просмотра; хоткей в композере всегда создаёт новый блок.
- Постобработка при продолжении прогоняется только по новой части.
