# 10 — Engine Download: модель

Спецификация: `.scratch/voice-dictation-3/spec.md`. Словарь: `CONTEXT.md`.

**What to build:** У поля «Whisper Model Path» на подстранице Dictation появляется кнопка «Download…» со списком из четырёх моделей whisper.cpp с размерами: large-v3-q5_0, large-v3-turbo-q5_0, medium-q5_0, small-q5_1. Выбор запускает загрузку с HuggingFace через HTTP-клиент Zed в папку `dictation\models` data dir; в строке поля виден процент и Cancel; по завершении SHA1 сверяется с закреплённой в коде, при совпадении `model_path` записывается в `settings.json`, при несовпадении файл удаляется и на подстранице Banner с ошибкой; Cancel удаляет частичный файл. Загрузчик процесс-глобальный: закрытие окна Settings её не отменяет, при повторном открытии прогресс виден. Кнопка доступна всегда. Докачки нет.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Ручная проверка: загрузка small-q5_1 показывает прогресс, после неё `model_path` указывает на файл в data dir и диктовка работает на новой модели.
