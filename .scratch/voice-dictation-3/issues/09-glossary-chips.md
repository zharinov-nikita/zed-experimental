# 09 — Glossary чипами

Спецификация: `.scratch/voice-dictation-3/spec.md`. Словарь: `CONTEXT.md`. Образец: компонент `Chip` в крейте `ui`.

**What to build:** На подстранице Dictation глоссарий показан чипами в строку с переносом, у каждого крестик удаления, поле добавления стоит последним. Ввод или вставка «TypeScript, Docker, Kubernetes» в поле добавления даёт три чипа; дубликаты и пустые части отбрасываются. Правка термина это удалить и добавить. Всё по-прежнему пишет полный список в `agent.dictation.glossary`, умолчания сохраняются, как в итерации 2.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Тест разбиения списка через запятую рядом с существующими тестами хелперов глоссария: пробелы обрезаются, пустые и повторы отбрасываются, порядок сохраняется.
- [ ] Ручная проверка: семнадцать терминов по умолчанию занимают несколько строк чипов, крестик удаляет один термин, вставка списка даёт несколько чипов.
- [ ] Правка `settings.json` отражается на чипах.
