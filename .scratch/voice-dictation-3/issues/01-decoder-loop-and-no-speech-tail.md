# 01 — Decoder Loop и no-speech хвост

Спецификация: `.scratch/voice-dictation-3/spec.md`. Словарь: `CONTEXT.md`. Решение о границе: `docs/adr/0001-decoder-loop-guard-stays-in-the-engine.md`.

**What to build:** Диктовка «1, 2, 3, 4, 5» с паузой в конце даёт ровно эти цифры. Пока Transcription Engine крутит Decoder Loop на почти пустом буфере, Pending Text пустой, а Confirmed Text не растёт мусором. При остановке хвост, который декодер сам считает тишиной, не добавляется, и «Thank you.» в тексте не появляется ни с Post-processing, ни без него. Движок судит только форму вывода: сегмент из одной n-граммы, повторённой три и более раз, отбрасывается; словарных решений в движке нет. Промпт Post-processing по умолчанию получает «Thank you» в примерах артефактов. Для интеграционного теста нужна фикстура: запись цифр с тишиной в конце, снятая текущим `save_last_recording` и положенная рядом с записями Handy; тест включается теми же переменными окружения, что и существующие.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Детектор повтора n-граммы проверен как чистая функция на синтетических строках: повтор из трёх и более, отсутствие повтора, нормальная речь с одним повторившимся словом остаётся.
- [ ] Интеграционный тест на фикстуре цифр: ни одно обновление Live Transcript не содержит повторённую n-грамму, итоговый текст не содержит ничего после последней цифры.
- [ ] Хвост при остановке с высокой вероятностью no-speech отбрасывается; существующие тесты на записях Handy по-прежнему зелёные.
- [ ] Промпт по умолчанию в `assets/settings/default.json` упоминает «Thank you»; тест на плейсхолдеры зелёный.
- [ ] Ручная проверка в dev-сборке: цифры с паузой без петли и без «Thank you».
- [ ] `./script/clippy` и `cargo test -p dictation` зелёные, раздел про диктовку в `LOCAL_DEV.md` дополнен фикстурой.
