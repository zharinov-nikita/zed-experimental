# 06 — Устройства: имена как в Windows, обновление списка, Test Microphone

Спецификация: `.scratch/voice-dictation-3/spec.md`. Словарь: `CONTEXT.md`.

**What to build:** Аудиоустройства везде называются как в Windows: «Microphone (fifine Microphone)» вместо «Microphone (wasapi:{…})», идентификатор остаётся только в тултипе. Правка в крейте `audio` fork-локальным блоком, действует на страницу Audio, окно проверки звука и подстраницу Dictation. Список устройств перечисляется заново при каждом открытии выпадающего списка микрофона и при старте Dictation Session, так что микрофон, подключённый после запуска Zed, виден без перезапуска. Движок сообщает, какое устройство реально открыл и был ли fallback с настроенного на устройство по умолчанию. На подстраницe Dictation кнопка «Test Microphone…» открывает существующее окно проверки звука.

**Blocked by:** None — can start immediately.
