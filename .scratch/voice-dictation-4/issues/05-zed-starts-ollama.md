# 05 — Zed поднимает Ollama

Спецификация: `.scratch/voice-dictation-4/spec.md`. Словарь: `CONTEXT.md`.

**What to build:** При старте Dictation Session, если провайдер Post-processing это Ollama с адресом по умолчанию на `localhost` и сервер не отвечает, Zed в фоне запускает приложение Ollama, найденное рядом с исполняемым файлом `ollama` из PATH, а без приложения запускает `ollama serve` скрытым процессом, и опрашивает сервер до двадцати секунд. Post-processing ждёт лаунчер прежде чем выбирать модель; пока ждёт, спиннер в подвале называется «Starting Ollama…». Если сервер так и не ответил, Post-processing не запускается: просмотр показывает Callout «Ollama did not start», текст остаётся сырым, подмены моделью агента по умолчанию нет. Неудача не мешает следующей Dictation Session попробовать снова. Для удалённого адреса Ollama и для других провайдеров Zed ничего не запускает; fallback на модель агента по умолчанию остаётся только когда модель Post-processing вообще не задана. Лаунчер получает проверку доступности и запуск процесса снаружи, так что тесты не поднимают реальный сервер.

**Blocked by:** None — can start immediately.
