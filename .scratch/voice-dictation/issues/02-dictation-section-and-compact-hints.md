# 02 — Dictation Window как секция над Composer, компактные подсказки

Спецификация: `.scratch/voice-dictation/spec.md`. Словарь: `CONTEXT.md`. Первичный источник вида: прототип `prototypes/voice-dictation/index.html`, вариант C «Section над композером».

**What to build:** Dictation Window больше не плавает у курсора. Она разворачивается внутри панели агента прямо над Composer на всю его ширину и сдвигает Composer вниз; когда сессии нет, секции нет. Тело растёт вместе с текстом до 10 строк, дальше прокрутка, одинаково для записи и просмотра, чтобы высота не прыгала при остановке. Подвал остаётся одной строкой: слева индикатор и таймер, справа подсказки уменьшенного размера. Подсказки с `ctrl-alt-space` (Accept в записи, Resume в просмотре) убраны; в записи остаётся «esc Review», в просмотре «enter Accept», «tab Raw / Processed», «esc Cancel». Подсказки по-прежнему кликабельны. Тултип кнопки микрофона перечисляет «Start / Stop dictation» и «Resume selected block» с хоткеем. Код позиционирования у курсора и оверлей удаляются. Фокус: Composer во время записи, редактор просмотра в просмотре.

**Blocked by:** None — can start immediately.

**Status:** implemented, not verified by hand (коммит 7d6f97ce60) — код написан, clippy и тесты зелёные; пункты ниже без галочки требуют ручной проверки в dev-сборке

- [ ] Длинная диктовка (более 10 строк) прокручивается внутри секции и не выталкивает Composer.
