# 07 — Post-processing на подстранице Dictation

Спецификация: `.scratch/voice-dictation/spec.md`. Словарь: `CONTEXT.md`. Образцы вёрстки внутри `settings_ui`: выбор модели Ollama (список из внешнего источника) и многострочный редактор из Skill Creator.

**What to build:** Ниже полей движка подстраница Dictation получает блок Post-processing: переключатель «Enabled»; выпадающий список провайдера из реестра языковых моделей и второй список моделей выбранного провайдера, вместе они пишут `agent.dictation.post_processing.model` как пару провайдер+модель, а очистка провайдера удаляет выбор, чтобы снова использовалась модель агента по умолчанию; многострочный редактор промпта с мягким переносом, описанием плейсхолдеров `${glossary}` и `${output}` и кнопкой «Reset to default», возвращающей короткий промпт из умолчаний. Всё пишет в `settings.json`.

**Blocked by:** 06 — Подстраница Settings > AI > Dictation, поля движка.
