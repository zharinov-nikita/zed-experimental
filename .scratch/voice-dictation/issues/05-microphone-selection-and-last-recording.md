# 05 — Выбор микрофона и WAV последней сессии

Спецификация: `.scratch/voice-dictation/spec.md`. Словарь: `CONTEXT.md`.

**What to build:** Запись идёт с устройства, выбранного в `audio.input_audio_device` (то же поле, что на странице Audio). Для этого доделывается закомментированный путь выбора устройства в конвейере записи крейта `audio`; устройство по умолчанию используется, если настройка пуста или устройство не найдено (с предупреждением в лог). При включённом `save_last_recording` весь PCM сессии сохраняется как 16 кГц mono WAV в один фиксированный файл во временной папке ОС, перезаписываемый каждой сессией; путь пишется в лог уровня info. Файл открывается примером `transcribe_wav` и годится для интеграционных тестов из тикета 04.

**Blocked by:** 01 — Поля настроек диктовки (`save_last_recording`); 04 — Цикл распознавания (новый источник звука).
