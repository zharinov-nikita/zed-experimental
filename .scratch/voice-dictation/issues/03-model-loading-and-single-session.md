# 03 — Model Loading и одна Dictation Session на процесс

Спецификация: `.scratch/voice-dictation/spec.md`. Словарь: `CONTEXT.md`.

**What to build:** Пользователь видит Model Loading. Пока модель грузится, в теле секции написано «Loading Whisper model…», таймер, красная точка и подсказки (кроме «esc Cancel») не показываются. Микрофон открывается только после загрузки модели, сказанное во время загрузки не пишется. После сессии модель остаётся в памяти до закрытия Zed, если включён `keep_model_loaded`; если выключен, модель выгружается сразу после сессии. Одна Dictation Session на процесс: старт во втором окне Zed при активной сессии в первом показывает в секции Callout «Dictation is already running in another window», ничего не пишет и не трогает кеш модели (вторая копия Whisper не загружается). Resume существующего Dictation Block пользуется загруженной моделью.

**Blocked by:** 01 — Поля настроек диктовки (флаг `keep_model_loaded`).
