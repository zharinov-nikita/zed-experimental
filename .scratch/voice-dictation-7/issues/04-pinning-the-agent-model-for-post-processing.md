# 04 — Выбор модели агента для Post-processing

**What to build:** Пользователь указывает в настройках Post-processing, какой моделью агента переписывать, и получает именно её — при том что его рабочий тред с тем же агентом остаётся на своей модели. Дешёвая модель для чистки диктовки, дорогая для работы, одновременно.

Post-processing Session не наследует ничего из настроек агента, сохранённых для рабочих тредов: её опции выставляются явно и только те, которые агент объявил при создании этой сессии. Опция, которой агент не объявил, не выставляется вовсе — это защищает от настроек, валидных для одной модели и невалидных для другой.

Выбор «модель агента по умолчанию» остаётся доступным как явное значение, а не как следствие пустоты. Подпись у результата называет агента и выбранную модель.

Спека: `.scratch/voice-dictation-7/spec.md`, «Политика Post-processing Session» и «Просмотр».
