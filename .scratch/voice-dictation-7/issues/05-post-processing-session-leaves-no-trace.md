# 05 — Post-processing Session не засоряет историю агента

**What to build:** Список недавних тредов агента остаётся про работу пользователя. Post-processing Session там не появляется: по завершении Dictation Session она удаляется у самого агента, а для агентов, которые удаление сессий не поддерживают, она не показывается в списке тредов Zed.

Сейчас список тредов Zed берёт у агента, а не у себя, и агент свои сессии сохраняет: без этого тикета каждая надиктовка оставляла бы по треду рядом с настоящими разговорами.

Спека: `.scratch/voice-dictation-7/spec.md`, «Post-processing (`agent_ui`, новый модуль)», последний абзац про жизненный цикл.

**Blocked by:** 03.

**Status:** implemented, awaiting manual check on a dev build
