# 03 — Первое переписывание через External Agent

**What to build:** Пользователь прописывает в настройках, что Post-processing выполняет External Agent, надиктовывает — и получает переписанный текст, сделанный агентом на его собственной модели по умолчанию. Ollama при этом не запускается и не нужна.

Переписывание идёт в Post-processing Session: отдельной сессии того агента, созданной на соединении, которое Zed для него уже держит, — второго процесса не появляется. Сессия помечена «только текст», получает пустой рабочий каталог и самый строгий из режимов, которые агент объявил. Она живёт одну Dictation Session: Resume переписывается в ней же, следующая диктовка начинает с новой.

Ответа ждём не дольше предела; если он истёк, агент недоступен, отказался или попытался действовать — Post-processing не выполнено, пользователь остаётся с сырым текстом и видит Callout. Пока идёт ожидание, футер показывает, что переписывание в работе. Подпись у результата называет агента.

Настройка на этом этапе редактируется руками в `settings.json`; страница настроек появится в 06.

Спека: `.scratch/voice-dictation-7/spec.md`, разделы «Настройки», «Post-processing», «Просмотр».
